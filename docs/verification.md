```powershell
node scripts/build.cjs
```

## 通过的检查

- 390×844、768×1024、1440×900、1920×1080，中文和英文共八组配置。
- 四份项目的目录选择与预览联动；单一选中状态。
- 进入详情、页面返回按钮、浏览器后退；返回时恢复选中项目和阅读位置。
- 四个详情页的直接访问与刷新，正文、资源路径与后续项目入口正常。
- 横向溢出、长标题、正文与固定导航边界。
- 《囚城营救》标题画面和游戏内截图真实解码，按完整比例展示。
- 中文和英文页面标题、文案切换与语言持久化。
- Tab、方向键、Home/End 切换项目；Enter 打开详情。
- 减少动态效果模式下可完整操作，无强制开场、自动播放或滚动锁。
- 邮箱复制读取到预期值；未发送任何邮件或消息。
- `file://` 直接打开首页并进入项目详情。
- 禁用 JavaScript 时首页保留直接项目入口，详情正文仍可阅读。
- 自动化过程中没有捕获到页面脚本异常或站内 4xx/5xx 请求。
