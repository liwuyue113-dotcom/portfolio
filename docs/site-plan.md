## 原型方向与阶段

在既有原生 HTML/CSS/JS 技术栈上改造：开阔首屏 → 作品档案 → 个人能力 → 联系方式。
四份项目档案可切换预览，进入四个静态详情页；支持详情直达、刷新和返回时恢复选择与位置。
首页手机端：精简顶栏、横向项目索引、纵向项目预览；保留正文可读性和触屏操作。

当前阶段：独立 Git 分支 portfolio-archive-prototype 中制作可评审原型。既有 main 与线上页面保留。
用户确认具体版式后，继续最终实施、合并及已授权的 GitHub Pages 更新。

## 维护与运行

唯一内容入口：data/portfolio.json。
模板：js/views.js。行为：js/main.js。样式：css/style.css。
静态生成：node scripts/build.cjs。
本地预览：python -m http.server 8766 --bind 127.0.0.1，从该工作树根目录执行。
直接打开 index.html 也可预览；发布时保持 js、css、images、projects 的相对目录结构。
Git 管理阶段版本，避免复制代码目录作为备份。
